About the Shared Framework Repository

A centralized compliance data service for security, privacy, and risk frameworks

The Shared Framework Repository (SFR) centralizes, normalizes, and exposes metadata about the world's most widely used security, privacy, and risk compliance frameworks. It is built from the canonical Secure Controls Framework (SCF) workbook, which cross-maps thousands of controls across 170+ global frameworks.

SFR is designed for use in Third-Party Risk Management (TPRM), Governance, Risk & Compliance (GRC), and automated compliance tooling. Whether you're assessing a vendor, comparing frameworks, or building compliance automation, SFR provides the canonical data layer you need.

Data Source

All data is loaded from the canonical Secure Controls Framework (SCF) 2026.1 workbook, published by the Secure Controls Framework Council. The SCF provides:

  • A master catalog of controls mapped to 170+ global frameworks
  • Firm-size solution guidance (micro to enterprise)
  • SCR-CMM maturity level definitions (levels 0–5)
  • Relative control weighting for prioritization
  • PPTDF applicability classification (People, Process, Technology, Data, Facility)
  • Threat and risk catalogs with materiality considerations
